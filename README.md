# Sonntagsfrage Sachsen-Anhalt – interaktives Balkendiagramm

Einzelne HTML-Datei ohne Abhängigkeiten (`index.html`), für die Nutzung auf dem Smartphone ausgelegt.

- Ausgangswerte: Politbarometer (Forschungsgruppe Wahlen für das ZDF), Umfrage vom 1.–3.9.2026, 1044 Befragte.
- Jede Spalte lässt sich per Wischgeste nach oben oder unten in der Höhe verändern; der Prozentwert folgt proportional in 0,5 %-Schritten.
- Die Anzeige über dem Diagramm zeigt die Summe aller Balken und ob sie unter, genau bei oder über 100 % liegt.
- Tastatur: Spalte fokussieren, Pfeiltasten (0,5 %), Bild auf/ab (5 %), Pos1 (0 %).
- Schaltflächen: Umfragewerte wiederherstellen, Summe auf 100 % normieren.

Öffnen: `index.html` im Browser laden, kein Build nötig.
